title=PhunServer Tools
description=PhunServer is an essential lightweight mod for multiplayer Project Zomboid servers.
description=Designed for admins who want automation, safety, and quality-of-life without babysitting their server.
description=[h2]TL;DR[/h2]
description=[list]
description=[*]Automatically monitors Workshop mods and can trigger a controlled shutdown when updates are detected
description=[*]Provides useful admin and player commands (/players, /hours, /sethours)
description=[*]Supports resetting the players map when seasons change or even if the player dies
description=[*]Allows independent day/night speeds
description=[*]Adds optional chat quality-of-life features (greetings, cleaner radio/music output)
description=[/list]
description=
description=[h2]PhunServer: Misc[/h2]
description=Various commands and server-side quality-of-life settings.
description=
description=Related commands:
description=[list]
description=[*][b]/players[/b] – Shows all online players. Can optionally include players who have been online in the last 24 hours.
description=[*][b]/hours <username?>[/b] – Returns hours survived. If no username is supplied (or the user is not an admin/mod), the issuing player is used. Target player must be online.
description=[*][b]/sethours <username?> <number>[/b] – Sets a player’s hours survived. Admins and moderators only. Target player must be online.
description=[/list]
description=
description=[table]
description=[tr][th]Setting[/th][th]Description[/th][/tr]
description=[tr][td][b]Players[/b][/td][td]Allow use of the /players command in chat to display online players[/td][/tr]
description=[tr][td][b]Include Recent Players[/b][/td][td]When using /players, also display players who have been online in the past 24 hours[/td][/tr]
description=[tr][td][b]Hours[/b][/td][td]Allow players to use /hours to display their own hours survived. Admins and moderators may query others[/td][/tr]
description=[tr][td][b]Set Hours[/b][/td][td]Allow admins or moderators to update a player’s hours survived[/td][/tr]
description=[tr][td][b]Debug[/b][/td][td]Enable more verbose debug output in the console and logs[/td][/tr]
description=[/table]
description=
description=[h2]PhunServer: Chat[/h2]
description=Ensure your players feel seen.
description=
description=[table]
description=[tr][th]Setting[/th][th]Description[/th][/tr]
description=[tr][td][b]Welcome Players[/b][/td][td]Send a notice to all players when someone joins or returns[/td][/tr]
description=[tr][td][b]Player Goodbye[/b][/td][td]Send a notice to all players when someone logs off[/td][/tr]
description=[tr][td][b]Replace img[/b][/td][td]Replace [image=music] tags in chat text with a music note icon. It’s prettier and cleaner. If you prefer uglier and dirtier, untick this[/td][/tr]
description=[tr][td][b]Replace Radio[/b][/td][td]Replace the prefix Radio(station#): with a speaker icon. This looks cleaner but removes the station source info[/td][/tr]

description=[h2]PhunServer: ModWatch[/h2]
description=Automatically monitor the Steam Workshop and trigger a controlled server shutdown when one or more mods have been updated.
description=Heavily inspired by the excellent [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2844315442]Udderly Up To Date[/url], which I otherwise could not live without.
description=
description=[b]Important:[/b] PhunServer does not restart your server automatically. It can trigger a shutdown, but you will still need a host, cron job, or service to bring the server back online. Once restarted, Steam will automatically update mods.
description=
description=Related commands:
description=[list]
description=[*][b]/check[/b] – Immediately checks the workshop for updated mods and triggers a restart countdown if any are found
description=[*][b]/restart <minutes?>[/b] – Trigger a restart with an optional countdown (0 = immediate). If omitted, the configured Countdown setting is used
description=[/list]
description=
description=[table]
description=[tr][th]Setting[/th][th]Description[/th][/tr]
description=[tr][td][b]Enable[/b][/td][td]Poll Steam for workshop updates and trigger a shutdown if any are found[/td][/tr]
description=[tr][td][b]Mod Update Notice[/b][/td][td]Minutes of notice given to players before shutdown[/td][/tr]
description=[tr][td][b]Quit Delay[/b][/td][td]Seconds to wait after saving before the server quits[/td][/tr]
description=[tr][td][b]Check for Updates[/b][/td][td]Minutes between workshop update checks[/td][/tr]
description=[tr][td][b]Countdown[/b][/td][td]Semicolon-separated seconds for announcements (e.g. 30;20;10)[/td][/tr]
description=[tr][td][b]Chime[/b][/td][td]Play a short sound when restart notices are sent[/td][/tr]
description=[/table]
description=
description=[h2]PhunServer: Maps[/h2]
description=Settings that control player visibility on maps and allow controlled map wipes for resets or seasons.
description=[table]
description=[tr][th]Setting[/th][th]Description[/th][/tr]
description=[tr][td][b]Enable Map Wipes[/b][/td][td]Untick to completely disable all map wiping behaviour[/td][/tr]
description=[tr][td][b]Wipe Map[/b][/td][td]Untick if you only want to wipe symbols and annotations[/td][/tr]
description=[tr][td][b]Wipe Symbols[/b][/td][td]Untick if you only want to wipe the map itself[/td][/tr]
description=[tr][td][b]Wipe Per Character[/b][/td][td]Trigger a map wipe when a new character is created (e.g. on death)[/td][/tr]
description=[tr][td][b]Wipe Key[/b][/td][td]If this value changes (e.g. Season 5 → Season 6), player maps will be wiped on next login[/td][/tr]
description=[tr][td][b]Players on Map (Deprecated)[/b][/td][td]Allow players to see each other on the map. Deprecated as B42 includes this feature[/td][/tr]
description=[tr][td][b]Players on Mini Map (Deprecated)[/b][/td][td]Allow players to see each other on the mini-map. Deprecated as B42 includes this feature[/td][/tr]
description=[/table]
description=Note that (when enabled) a players map is wiped when their wipekey differs from the one in your settings. This is evaluated at login or when a character is created (e.g. a respawn after death), 
description=

description=[h2]PhunServer: Cycles[/h2]
description=Settings that allow you to control the start, end, and speed of day/night cycles.
description=
description=[table]
description=[tr][th]Setting[/th][th]Description[/th][/tr]
description=[tr][td][b]Enable Day/Night Changes[/b][/td][td]Untick to prevent PhunServer from modifying day/night speeds[/td][/tr]
description=[tr][td][b]Night Speed[/b][/td][td]Time it takes for a night to pass[/td][/tr]
description=[tr][td][b]Dusk Offset[/b][/td][td]Adjust dusk start time (+/- hours). Example: -1 starts night one hour earlier[/td][/tr]
description=[tr][td][b]Day Speed[/b][/td][td]Time it takes for a day to pass[/td][/tr]
description=[tr][td][b]Dawn Offset[/b][/td][td]Adjust dawn start time (+/- hours). Example: 1 starts dawn one hour later[/td][/tr]
description=[/table]
