title=PhunServer 2
description=PhunServer 2 is a set of lightweight, independent server tools for multiplayer Project Zomboid.
description=Every module is its own mod id, so you load only the pieces you actually want.
description=
description=[b]This is a rewrite of [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3623897097]PhunServer Tools[/url] and replaces it.[/b] Settings do NOT carry over; see the notes at the bottom.
description=
description=[h2]Modules[/h2]
description=[table]
description=[tr][th]Mod Id[/th][th]What it does[/th][/tr]
description=[tr][td][b]phunserver2[/b][/td][td]Required by all the others. Shared plumbing, shutdown machinery and admin diagnostics.[/td][/tr]
description=[tr][td][b]phunserver2cron[/b][/td][td]Scheduled jobs on the real-world clock or the game clock, plus ModWatch.[/td][/tr]
description=[tr][td][b]phunserver2commands[/b][/td][td]The /players, /hours and /sethours chat commands.[/td][/tr]
description=[tr][td][b]phunserver2chat[/b][/td][td]Join and leave announcements, username highlighting, tidier radio and music lines.[/td][/tr]
description=[tr][td][b]phunserver2daynight[/b][/td][td]Independent day and night speeds with dawn and dusk offsets.[/td][/tr]
description=[tr][td][b]phunserver2wiper[/b][/td][td]Map and symbol wipes on a season change or a new character.[/td][/tr]
description=[/table]
description=
description=Example, mod-update restarts only:
description=[code]Mods=phunserver2;phunserver2cron[/code]
description=
description=Every setting has an in-game tooltip. Commands are typed in game chat, not the server console or RCON ([url=https://github.com/PhunZoider/PhunServer/blob/main/Docs/commands.md]why[/url]).
description=
description=[h2]PhunServer 2: Core[/h2]
description=Owns the shutdown countdown, so its settings apply to every restart however it was triggered.
description=
description=[b]Important:[/b] PhunServer never restarts your server. It shuts it down cleanly; bringing it back up (letting Steam apply mod updates) is your host's job.
description=
description=Related commands:
description=[list]
description=[*][b]/restart <minutes?>[/b] - Start a restart countdown. With no argument the ModWatch notice period is used.
description=[*][b]/cancelrestart[/b] - Cancel a pending restart.
description=[/list]
description=
description=[h3]Diagnostics[/h3]
description=Read-only admin tools for when the world is not what it should be.
description=[list]
description=[*][b]/diag[/b] - Probe the square you stand on. Client and server facts (power, buildings, zones) side by side, differences in red.
description=[*][b]/diag <x> <y> <z?>[/b] - Probe any square, even where nobody is standing.
description=[*][b]/diag health[/b] - Is every map in Map= installed, and did its zones load?
description=[/list]
description=Map health also runs at server start. If it finds a problem it logs MAP HEALTH lines and shows the window to admins as they join. It catches a Map= entry whose mod is inactive (later maps lose their buildings and indoor power) and a broken map file that leaves maps above it with no zones. [url=https://github.com/PhunZoider/PhunServer/blob/main/Docs/diagnostics.md]More[/url].
description=
description=[h2]PhunServer 2: Cron[/h2]
description=Schedule shutdowns, announcements, mod-update checks or Lua events on the real-world clock (at set times or on an interval) or on the game clock (at in-game times, or at dawn and dusk with Day/Night). Handy for switching a PhunZones profile when night falls.
description=
description=Jobs live in [b]<Zomboid>/Lua/PhunServer2Cron.json[/b], created on first run with a five minute mod-update check. See the [url=https://github.com/PhunZoider/PhunServer/blob/main/Docs/cron.md]cron guide[/url] for the format and examples.
description=
description=ModWatch needs the server running with Steam, and your mods' ids in [b]WorkshopItems=[/b] in the server ini. The engine only checks items it installed itself, so mods added by hand or a host panel cannot be checked. If either is missing the log says so.
description=
description=Related commands:
description=[list]
description=[*][b]/check[/b] - Check the workshop for updated mods right now.
description=[*][b]/cron reload[/b] - Re-read the job file without restarting.
description=[/list]
description=
description=ModWatch is heavily inspired by the excellent [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2844315442]Udderly Up To Date[/url].
description=
description=[h2]PhunServer 2: Commands[/h2]
description=[list]
description=[*][b]/players[/b] - Show who is online, optionally including anyone on in the last 24 hours.
description=[*][b]/hours <username?>[/b] - Hours survived. Admins and moderators can query another online player.
description=[*][b]/sethours <username?> <number>[/b] - Set a player's hours survived. Admins and moderators only.
description=[/list]
description=
description=[h2]PhunServer 2: Chat[/h2]
description=Make sure your players feel seen, and clean up the noisier parts of chat.
description=Greet returning players by name, colour usernames wherever they appear, and swap the [img=music] clutter and Radio (station): prefixes for clean icons. Admins can come and go without announcing themselves.
description=
description=[h2]PhunServer 2: Day/Night[/h2]
description=Run day and night at different speeds. The server decides and tells clients, so everyone agrees on what time it is.
description=Long days to build in, short nights for mercy, or the reverse if you would rather your players were afraid of the dark. Dawn and dusk shift separately. Cron jobs can run at dawn and dusk too.
description=
description=[h2]PhunServer 2: Wiper[/h2]
description=Wipe player maps when a season rolls over, or when a player rolls a new character.
description=
description=[b]It will never wipe anyone by surprise.[/b] Wiping is off by default, and a player seen for the first time is recorded, not wiped. Only a wipe key that changes after that wipes, so installing mid-season is safe.
description=
description=Related commands:
description=[list]
description=[*][b]/wipemap <username>[/b] - Wipe one online player's map now.
description=[*][b]/wipemap all[/b] - Wipe every online player's map now.
description=[/list]
description=
description=[h2]Coming from PhunServer 1?[/h2]
description=Remove [b]phunserver[/b] from your Mods line and add the modules you want. PhunLib is no longer required. Settings moved to per-module names; the [url=https://github.com/PhunZoider/PhunServer/blob/main/Docs/migrating.md]migration guide[/url] maps old to new.
description=
